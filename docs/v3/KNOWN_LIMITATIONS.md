# V3 limitations

- This is a personal local app with SQLite/media persistence on the machine running its server. Vercel project context is linked; the full backend is not deployed. Public identity/ownership, durable hosted data and deployment verification remain required.
- Copilot/Practice prepare editable evidence outlines using deterministic rules and the user's selected notes. They are not AI-generated interview answers. Unknown facts remain placeholders. Topic matching is keyword-based, not calibrated model confidence. No automated practice quality score or speaker diarization is claimed.
- Browser SpeechRecognition is optional, may use the browser vendor's network service, and varies by browser. Permission disclosure, manual input and error paths exist. Live external recognition, real microphone quality and speaker separation were not verified in automated tests. Browser TTS voices differ; mascot animation is illustrative rather than audio lip-sync.
- Configured AI inference remains in the existing server adapter boundary. Test fixture provider success is not live AI verification. No keys, accounts, subscriptions, Firebase services or paid storage were created.
- Marketplace is a labeled collection of original local starters, not a commerce backend. No fake orders, creator profiles, prices, licensing purchases or payment success are displayed. Public community and remote collaboration are unavailable.
- Existing Canvas remains the same single-select document editor. It has save/revisions/history/keyboard movement; advanced grouping/locking/snapping and remote collaboration are not added by the visual rewrite.
- Original Motion Lab effects are retained with their V2 authoring limits. SVG physics is spring-based, not a rigid-body collision engine. Real-device sensors/multitouch, GPU context recovery and sustained FPS across devices still need testing.
- Main navigation, new screens and selected common studio/editor controls are bilingual; advanced technical and legacy explanatory copy still includes English. User documents, starter artwork and code are not automatically translated.
- Automated axe checks cover specified default states and workflows, not certification or every screen-reader/error/focus combination. Static screenshots do not prove motion. Browser viewport simulation does not replace real iPad/phone testing.
- Exact six reference image files named in the earlier Prompt Pack are not present under design/references. This is an intentional merged redesign based on supplied written values, existing assets and visible references; no pixel-sampling or screenshot reconstruction claim.
- Unsaved drafts/preferences remain browser-local and are not part of the persistent server backup. Recovery copies were preserved before migration; no user records, hosting, remote repository or access policy was deleted.
