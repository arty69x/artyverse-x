# ARTYVERSE — The Artist’s Multiverse

Brand direction 1.0 · Artist × Multiverse · Proposed identity, not a claim that every product capability is already connected.

## Brand essence

ARTY มาจาก **Artist** และ VERSE มาจาก **Multiverse**: ศิลปินหนึ่งคนสามารถสร้างโลกได้หลายแบบ ผ่านภาพ เสียง ตัวอักษร โค้ด และประสบการณ์ที่มีตัวตนของตัวเอง

**One artist. Infinite worlds.**
**ศิลปินหนึ่งคน โลกสร้างสรรค์ไร้ขีดจำกัด**

ARTYVERSE เป็นแบรนด์ของ creative intelligence workspace ที่ให้ผู้สร้างเปลี่ยนคำถามเป็นความเข้าใจ เปลี่ยนความเข้าใจเป็นชิ้นงาน และพัฒนาชิ้นงานด้วยหลักฐานที่ตรวจสอบได้

## Positioning

สำหรับศิลปิน นักออกแบบ creative developer และทีมสร้างสรรค์ที่ต้องใช้หลายเครื่องมือ ARTYVERSE เชื่อมบทสนทนา การสร้างงาน การวิเคราะห์ และการส่งมอบไว้ในพื้นที่เดียว โดยรักษาที่มาของงาน เปิดเผยสถานะของระบบ และให้ผู้ใช้ควบคุมการเปลี่ยนแปลง

**Creative Intelligence, Proven.** เป็น strategic statement: ความสามารถสร้างสรรค์ที่แสดงผลและตรวจสอบย้อนกลับได้ คำว่า Proven ต้องมาพร้อมหลักฐานของงานหรือความสามารถที่กล่าวถึง ไม่ใช้เป็นตรารับรองลอย ๆ

## Three brand values

| Value | ความหมาย | แสดงออกในผลิตภัณฑ์อย่างไร | หลักฐานที่ควรมี |
|---|---|---|---|
| Creativity | เปิดพื้นที่ให้ผู้สร้างมีมุมมองของตนเอง | canvas, code, voice และการปรับแต่งที่แก้กลับได้ | ชิ้นงานที่แก้ไขและส่งออกได้จริง |
| Transparency | บอกสิ่งที่ระบบทำ รู้ และยังทำไม่ได้ | provider status, source records, review before apply, local/cloud distinction | ที่มา สถานะ request และประวัติการแก้ไข |
| Measurable impact | ให้ผลลัพธ์มีเกณฑ์ประเมินที่สอดคล้องกับงาน | preview, revision comparison, verification report, recoverable export | เวลา/ความครบถ้วน/ผลตรวจที่วัดจริงภายใต้เงื่อนไขที่ระบุ |

ไม่ใช้ตัวเลขสวย ๆ แทนหลักฐาน ไม่ทำ progress ปลอม และไม่ถือว่า output ดูดีเท่ากับงานผ่านการตรวจสอบ

## Five operating pillars

### THINK — คิดให้ชัด
ตั้งคำถาม สนทนา เก็บบริบท และพัฒนาความคิดก่อนลงมือ เครื่องมือ: conversational workspace, research notes, source records และ project memory เมื่อเชื่อมจริง

### CREATE — สร้างให้เป็นรูป
สร้างภาพ เอกสาร เสียง และโค้ดในพื้นที่เดียว เครื่องมือ: editable canvas, templates, voice recording; live-coding studio, sandboxed IDE และ procedural Web Audio synthesizer เป็น product vision ที่ต้องพัฒนาหรือเชื่อมต่อเพิ่ม

### ANALYZE — เข้าใจด้วยหลักฐาน
แสดงที่มา ตรวจความสอดคล้อง เปรียบเทียบ revisions และอธิบายข้อจำกัด เครื่องมือ AI analysis ต้องระบุ provider และแยกจากการตรวจด้วยกฎหรือข้อมูลที่ผู้ใช้ป้อน

### HYPER-POLISH — ขัดเกลาจนมีเหตุผล
ความประณีตเกิดจาก hierarchy, typography, responsive layout, motion และคุณภาพการใช้งาน ไม่ใช่การเพิ่มเอฟเฟกต์ทุกจุด เครื่องมือในวิสัยทัศน์: visual CSS inspector, sandboxed AI auto-fix, preview/diff และ checks ที่ตรวจซ้ำได้

### DRIVE — พางานไปถึงผลลัพธ์
เชื่อมขั้นตอน อนุมัติการเปลี่ยนแปลง ส่งออก และกลับมาพัฒนาต่อ เครื่องมือ: local workflow/export ที่มีอยู่ และ multi-step AI pipeline, external actions, multi-user collaboration เมื่อมี backend/สิทธิ์/การทดสอบจริง

## Brand architecture

- **ARTYVERSE** — master brand; ใช้ในโลโก้ เรื่องราว และการสื่อสารหลัก
- **ARTYVERSE X** — flagship creative workspace / studio product
- **Arty** — ชื่อ companion; มีบุคลิกฉลาด ใจเย็น ช่างสงสัย
- Think, Create, Analyze, Hyper-Polish, Drive — ชื่อ pillars และ workflow vocabulary ไม่สร้างห้าแบรนด์ย่อยที่แข่งกัน
- Design OS / Motion Lab / Voice Studio / Live Studio — ชื่อเครื่องมือภายในผลิตภัณฑ์

## Visual concept — Luminous Multiverse

**Cinematic cyberpunk ที่มีระเบียบและพื้นที่หายใจ**: ใช้แสงสร้างทิศทาง ใช้พื้นดำรักษาสมาธิ ใช้สีรองแยกโลกของเครื่องมือ และใช้กริดที่เปลี่ยนสัดส่วนตามงาน

### Symbol concept — Orbital A

โครง A สื่อถึง Artist และจุดเริ่มต้น เส้นวงโคจรที่ตัดผ่านสื่อถึง Multiverse และการเปลี่ยนผ่านระหว่างสื่อ รักษารูปทรงให้ใช้สีเดียวได้และไม่พึ่ง glow เพื่อให้อ่านออก มี native SVG ใน assets/artyverse-symbol.svg

เป็นแนวโลโก้ที่ออกแบบใหม่ในชุดนี้ ยังไม่ได้ตรวจ trademark clearance ความซ้ำของเครื่องหมาย หรือจดทะเบียน

### Palette

- Void Black `#060608` — พื้นที่หลัก
- Studio Surface `#0D0D12` — พื้นผิวทำงาน
- Starlight `#F0F0F8` — ตัวอักษรหลัก
- Signal Muted `#A3A3B6` — ข้อมูลรอง
- Artist Lime `#CCFF00` — action และจุดโฟกัสของแบรนด์
- Portal Cyan `#43E6FF` — signal / sound / technical context
- Multiverse Violet `#9B43FF` — spatial / visual experimentation
- Pulse Magenta `#D847ED` — accent ในงานภาพ ใช้ปริมาณน้อย

พื้นดำและ neutral เป็นส่วนใหญ่ Lime เป็น accent หลัก สีรองใช้เฉพาะบริบท ไม่วางข้อความยาวบนสีแสงจ้า และตรวจ contrast ทุกครั้งเมื่อเปลี่ยนคู่สี

### Typography

Space Grotesk สำหรับ display/heading, DM Sans สำหรับ body/UI, Noto Sans Thai สำหรับภาษาไทย ใช้ mono กับ metadata และ code เท่านั้น รูปโลโก้ตัวอักษรควรทำ optical refinement และส่งออก outlined artwork ในขั้น final identity production

### Layout

Desktop: asymmetric Bento Grid มีหนึ่งพื้นที่หลัก ตามด้วยพื้นที่รองที่มีหน้าที่จริง ความไม่สมมาตรต้องสัมพันธ์กับความสำคัญของงาน

Mobile-first: อ่านและทำ primary task ได้ในคอลัมน์เดียว controls สำคัญเป้าหมาย 44–48px editor inspector ไปอยู่ sheet/ส่วนล่าง ไม่ย่อหน้าจอ desktop ทั้งหน้าให้เล็กลง

### Materials and motion

พื้นผิวดำคม ขอบบาง เส้น orbital และแสงที่ขอบวัตถุ ไม่ทำ glass/neon glow ทุก card ใช้ WebGL เป็น optional visual enhancement พร้อม static fallback พื้นที่พิมพ์และอ่านต้องสงบ Motion เคารพ reduced motion และหยุดเมื่อไม่จำเป็น

## Arty — Living companion

Arty เป็นเพื่อนร่วมงานที่รับรู้บริบทโดยแสดงเฉพาะสถานะที่มีจริง: idle, focused, listening, working, success, error และ calm

Physics vision: spring settling, soft deformation, gaze และ orbital movement ที่มี velocity limits ไม่ติดตาม pointer อย่างรุนแรง Listening แสดงเฉพาะเมื่อ microphone active และ Working แสดงเมื่อมี request/job จริง มี SVG/static fallback, unique IDs และ cleanup

ไม่ทำให้มาสคอตดูเหมือนกำลังทำงานระหว่างที่ระบบไม่ได้ประมวลผล

## Voice and copy

น้ำเสียง: ตรง ชัด เป็นมิตร กล้าสร้างสรรค์ และอธิบายสิ่งที่เกิดขึ้นได้ ไม่อวดเกินหลักฐาน

**Hero**
ARTYVERSE
One artist. Infinite worlds.
คิด สร้าง วิเคราะห์ และขัดเกลางานของคุณ ในจักรวาลเดียว

Primary CTA: เริ่มสร้างโลกของคุณ / Start creating
Secondary CTA: สำรวจสตูดิโอ / Explore the studio
Composer placeholder: คุณอยากสร้างอะไรต่อไป? / What will you create next?

**Product narrative**
Think freely. Create boldly. Analyze clearly. Hyper-polish with purpose. Drive it forward.

**ข้อความที่ควรใช้**
- บันทึกในเครื่องแล้ว — พร้อมกลับมาแก้ต่อ
- แสดงการเปลี่ยนแปลงก่อนนำไปใช้
- ยังไม่เชื่อมต่อ AI — ใช้เครื่องมือในเครื่องต่อได้
- ตรวจแล้วภายใต้เงื่อนไขต่อไปนี้…

**ข้อความที่ต้องมีหลักฐานก่อนใช้**
- ตอบได้ทันทีทุกคำถาม / zero latency
- production-grade / production-ready
- realtime collaboration
- AI auto-fix / autonomous pipeline
- ประหยัดเวลา X% / แม่นยำ Y% / 60 FPS ทุกอุปกรณ์

ใช้ “จากคำถามสู่การลงมือทำ ในพื้นที่เดียว” เป็นคำสัญญาหลักที่ชัดกว่า “ตอบได้ทันทีทุกคำถาม”
